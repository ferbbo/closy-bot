## Objetivo

Corregir la clasificación de frases de selección post-búsqueda (p. ej. "lo quiero", "ese", "el primero") para que se clasifiquen como `ADD_TO_CART` (y no como `SEARCH_PRODUCT`) cuando el contexto previo es `lastIntent=SEARCH_PRODUCT`.

## Scope fence

### ✅ Included

- Extender keywords de `ADD_TO_CART` con frases de selección post-resultados.
- Agregar/ajustar tests unitarios que validen discriminación entre:
  - selección de un resultado (→ `ADD_TO_CART`), vs
  - continuación de búsqueda (→ `SEARCH_PRODUCT`).

### ❌ Excluded

- Cambios a `CONTEXT_BONUSES` (los valores actuales se mantienen).
- Cambios en flows (`AddToCartFlow`, `SearchCatalogFlow`) u orquestación.
- Cambios en endpoints, DB/migraciones, o UI.

### Keyword contract (REQ-01)

Se agregan las siguientes frases a `INTENT_KEYWORDS.ADD_TO_CART`:

| Frase | Peso | Justificación |
|-------|------|---------------|
| `lo quiero` | 5 | Supera "quiero" (2 en SEARCH_PRODUCT) + bonus SEARCH_PRODUCT→SEARCH_PRODUCT (3) cuando aplica |
| `eso` | 4 | Selección deíctica post-resultados |
| `ese` | 4 | Selección deíctica |
| `esa` | 4 | Selección deíctica |
| `el primero` | 5 | Referencia ordinal |
| `la primera` | 5 | Referencia ordinal |
| `el segundo` | 5 | Referencia ordinal |
| `la segunda` | 5 | Referencia ordinal |
| `el tercero` | 5 | Referencia ordinal |
| `la tercera` | 5 | Referencia ordinal |
| `el 1` | 5 | Referencia numérica |
| `el 2` | 5 | Referencia numérica |
| `el 3` | 5 | Referencia numérica |
| `me interesa` | 4 | Intención de compra explícita |
| `perfecto` | 3 | Confirmación |
| `me gusta` | 3 | Confirmación positiva |

## Comportamiento

- Happy path:
  - Dado `lastIntent=SEARCH_PRODUCT` y texto "lo quiero"/"ese"/"el primero" → `ADD_TO_CART` con confianza `HIGH`.
  - Dado `lastIntent=SEARCH_PRODUCT` y texto "y también vestido" → `SEARCH_PRODUCT` (continuación de búsqueda).
- Edge cases:
  - No se modifica el sistema de bonuses: la diferenciación se logra con keywords + tests de regresión.
